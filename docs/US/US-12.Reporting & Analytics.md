# 2. Epic Goal

Provide operational and management reports that support performance monitoring, historical analysis, decision-making, and continuous improvement across factories.

The module shall support standard reports, custom reports, scheduled reports, data export, and KPI analytics.

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-090 | Reports only include data from factories the user is authorized to access. |
| BR-091 | KPI calculations use aggregated telemetry data only. |
| BR-092 | Historical reports include archived data when available. |
| BR-093 | Saved report templates are user-specific unless explicitly shared. |
| BR-094 | Scheduled reports run automatically according to configured schedules. |
| BR-095 | Report exports reflect applied filters and sorting. |
| BR-096 | Every generated report shall be logged for audit purposes. |

# 7. Non-functional Considerations

## Performance

- Standard reports ≤ **5 seconds**
- Large reports ≤ **30 seconds**
- Export generation shall run asynchronously for large datasets

---

## Availability

Reporting services availability ≥ **99.9%**

---

## Scalability

Support:

- Multi-company
- Multi-factory
- Millions of historical records
- Long-term archived data

---

## Security

- Factory-level RBAC
- Export permission control
- Report access logging

---

## Reliability

- Report generation shall not impact real-time monitoring performance.
- Failed scheduled reports shall be retried automatically.
