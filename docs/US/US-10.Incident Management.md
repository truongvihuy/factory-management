# 2. Epic Goal

Provide a complete incident management workflow for industrial equipment.

The module shall support incident reporting, automatic incident creation from critical alerts, assignment, SLA tracking, investigation, resolution, verification, closure, and Major Incident management while maintaining full traceability.

# FT-INC-01 Incident Reporting

## US-INC-001 Create Incident

### Description

**As an** Operator

**I want** to report a machine incident

**So that** maintenance engineers can investigate and resolve the issue.

### Business Value

- Standardize incident handling.
- Reduce machine downtime.
- Improve maintenance response time.

### Priority

Critical

### Story Points

5

### Acceptance Criteria

Create incident with:

- Machine
- Factory
- Production Line
- Category
- Severity
- Description
- Reporter
- Occurred Time

Initial Status = **Open**

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-070 | One Incident shall reference one Machine. |
| BR-071 | Multiple Incidents may be linked to one Major Incident. |
| BR-072 | Incident workflow shall follow: Open → Assigned → In Progress → Resolved → Verified → Closed. |
| BR-073 | Critical incidents shall follow configured SLA targets. |
| BR-074 | Only Verified incidents may be Closed. |
| BR-075 | Root Cause Analysis is mandatory before closing an incident. |
| BR-076 | Incident history shall never be deleted. |
| BR-077 | Every incident operation shall generate an Audit Log. |

# 7. Non-functional Considerations

## Performance

- Incident creation ≤ **2 seconds**.
- Incident search ≤ **2 seconds**.

---

## Availability

Incident Management availability ≥ **99.9%**.

---

## Scalability

Support:

- Millions of incidents.
- Thousands of concurrent active incidents.
- Multiple factories.

---

## Security

- Users can only access incidents within authorized factories.
- Factory-level RBAC shall be enforced.

---

## Auditability

Audit Logs shall be generated for:

- Create
- Assignment
- Reassignment
- Status Change
- Work Log
- Root Cause Analysis
- Verification
- Closure
- Reopen
