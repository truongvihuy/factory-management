# 2. Epic Goal

Provide complete lifecycle management for industrial sensors.

The module shall support registering sensors, assigning sensors to machines, replacing sensors, transferring sensors between machines, and maintaining complete assignment history.

Sensor calibration and preventive inspection are managed as part of **Machine Maintenance**, not within this module.

# FT-SEN-01 Register Sensor

## US-SEN-001 Register Sensor

### Description

**As a** Maintenance Engineer

**I want** to register a new sensor

**So that** it can be assigned to industrial equipment.

### Business Value

- Centralize sensor information.
- Enable telemetry collection.
- Improve asset traceability.

### Priority

High

### Story Points

5

### Acceptance Criteria

#### AC-01 Successful Registration

**Given**

- User has permission.

**When**

A new sensor is registered.

**Then**

- Sensor is created.
- Status = Active.
- Audit Log generated.

---

#### AC-02 Duplicate Sensor Code

Sensor Code must be unique.

---

#### AC-03 Required Fields

Required fields include:

- Sensor Code
- Sensor Type
- Manufacturer
- Model
- Unit of Measurement

---

## US-SEN-009 Archive Sensor

Archive sensor.

- Currently attached to an active machine.
- Pending replacement exists.

Historical records remain available.

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-030 | Sensor Code shall be unique. |
| BR-031 | A sensor may be attached to only one machine at any point in time. |
| BR-032 | A machine may contain multiple sensors. |
| BR-033 | Transferring a sensor shall preserve complete assignment history. |
| BR-034 | Historical records shall never be deleted. |
| BR-035 | Sensor Code cannot be modified after creation. |
| BR-036 | Archived sensors become read-only. |
| BR-037 | Every change shall generate an Audit Log. |
