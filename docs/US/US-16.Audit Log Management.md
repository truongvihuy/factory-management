# 2. Epic Goal

Provide a centralized repository for managing reference data used throughout the Factory Management System.

Master Data shall ensure consistency, standardization, and reusability across all business modules while minimizing duplicated configuration.

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-170 | Every master data record shall have a unique code. |
| BR-171 | Master data codes are immutable after creation. |
| BR-172 | Master data referenced by business transactions cannot be physically deleted. |
| BR-173 | Inactive master data cannot be selected for new records. |
| BR-174 | All modifications shall be recorded in the Audit Log. |
| BR-175 | Import operations shall validate duplicate codes before processing. |

# 7. Non-functional Considerations

## Performance

- Search results ≤ 2 seconds.
- Import 10,000 records ≤ 5 minutes.

## Availability

- Service availability ≥ 99.9%.

## Security

- Factory-level RBAC where applicable.
- Audit logging for all changes.

## Scalability

Support thousands of master data records and future extensions without schema redesign.
