# 1. Overview

## 1.1 Purpose

This document defines the functional requirements for the **Dashboard Management** module.

The Dashboard Management module provides real-time operational visibility across factories by presenting machine status, telemetry, alerts, maintenance, incidents, and key performance indicators (KPIs).

Dashboards support different user roles, enabling users to monitor operations, detect abnormalities, and make timely decisions.

---

# 2. Business Scope

The module supports:

- Real-time Operational Dashboard
- Factory Dashboard
- Machine Dashboard
- Alert Dashboard
- Maintenance Dashboard
- Incident Dashboard
- KPI Dashboard
- Executive Dashboard
- Dashboard Filtering
- Dashboard Personalization

Dashboard data is read-only and is aggregated from other modules.

---

# 3. User Dashboards

Different user roles shall view different dashboard information.

| Role | Dashboard Focus |
|------|-----------------|
| Factory Manager | Overall factory operation |
| Production Supervisor | Machine and line status |
| Maintenance Engineer | Maintenance & incidents |
| Operator | Assigned machine status |
| Executive | Business KPIs |

Dashboard visibility shall follow Factory-level authorization.

---

# 4. Functional Requirements

---

# FR-DSH-001 View Factory Dashboard

The system shall display an overview of factory operations.

Displayed information includes:

- Factory Status
- Machine Status Summary
- Active Alerts
- Active Incidents
- Maintenance Overview
- Overall Equipment Effectiveness (OEE)
- Energy Consumption

---

# FR-DSH-002 View Machine Dashboard

The system shall display:

- Machine Status
- Latest Telemetry
- Running Hours
- Current Production Line
- Active Alerts
- Active Incident
- Next Maintenance

---

# FR-DSH-003 View Alert Dashboard

Display:

- Active Alerts
- Alerts by Severity
- Alerts by Factory
- Alerts by Machine
- Unacknowledged Alerts

---

# FR-DSH-004 View Maintenance Dashboard

Display:

- Upcoming Maintenance
- Overdue Maintenance
- Work Orders in Progress
- Maintenance by Type
- Maintenance Cost Summary

---

# FR-DSH-005 View Incident Dashboard

Display:

- Open Incidents
- SLA Violations
- Incidents by Priority
- MTTR
- MTBF
- Major Incidents

---

# FR-DSH-006 View KPI Dashboard

Display:

- OEE
- Availability
- Performance
- Quality
- Machine Utilization
- Downtime
- Production Output
- Energy Consumption

KPI definitions shall follow the business rules defined in the Reporting module.

---

# FR-DSH-007 Executive Dashboard

Executives shall view high-level business KPIs.

Display includes:

- Multi-Factory Overview
- Overall OEE
- Overall Downtime
- Maintenance Cost
- Total Energy Consumption
- Critical Alerts
- Open Incidents

---

# FR-DSH-008 Dashboard Filtering

Users shall filter dashboards by:

- Company
- Factory
- Workshop
- Production Line
- Machine Type
- Machine
- Time Range

Users shall only access authorized factories.

---

# FR-DSH-009 Real-Time Refresh

Dashboard information shall refresh automatically.

Target refresh interval:

- Every 1–2 seconds

Users shall not need to manually reload the page.

---

# FR-DSH-010 Drill-down Navigation

Users shall drill down from dashboard widgets.

Example:

Factory

↓

Workshop

↓

Production Line

↓

Machine

↓

Machine Detail

---

# FR-DSH-011 Machine Status Summary

Display total machines by status.

Supported statuses:

- Running
- Idle
- Stopped
- Maintenance
- Offline
- Error

---

# FR-DSH-012 Alert Summary

Display:

- Total Alerts
- Active Alerts
- Critical Alerts
- Warning Alerts
- Info Alerts
- Acknowledged Alerts

---

# FR-DSH-013 Maintenance Summary

Display:

- Planned Maintenance
- Completed Maintenance
- Overdue Maintenance
- Maintenance Cost
- Upcoming Maintenance

---

# FR-DSH-014 Incident Summary

Display:

- Open Incidents
- Resolved Incidents
- Closed Incidents
- SLA Violations
- Average Resolution Time

---

# FR-DSH-015 Telemetry Widget

Display near real-time telemetry for selected machines.

Examples:

- Temperature
- Vibration
- Pressure
- Energy Consumption
- Machine Speed

---

# FR-DSH-016 Dashboard Personalization

Users may configure:

- Favorite Dashboard
- Default Filters
- Widget Layout
- Preferred Time Range

User preferences shall be stored individually.

---

# FR-DSH-017 Dashboard Export

Users shall export dashboard data.

Supported formats:

- PDF
- Excel

Export shall respect user authorization.

---

# FR-DSH-018 Dashboard Performance Indicators

The system shall display:

- Dashboard Last Updated Time
- Data Refresh Status
- Gateway Connectivity Status

---

# FR-DSH-019 Dashboard Availability

If one widget fails to load:

- Remaining widgets shall continue functioning.
- Users shall receive an error indication for the affected widget only.

---

# FR-DSH-020 Audit Logging

The system shall record:

- Dashboard Export
- Dashboard Configuration Changes
- User Personalization Changes

Viewing dashboards shall not generate audit logs.

# 6. Non-functional Considerations

## Performance

- Dashboard pages shall load within **2 seconds**.
- Dashboard widgets shall refresh within **1–2 seconds**.
- Drill-down navigation shall complete within **2 seconds**.

---

## Availability

- Dashboard services should achieve **99.9% availability**.
- Critical monitoring widgets should target **99.99% availability**.

---

## Scalability

The dashboard shall support:

- 10 Companies
- 10 Factories
- 5,000 Machines
- 500 Million Telemetry Records per Day

without degradation of user experience.

---

## Security

- Dashboard data shall follow Factory-level authorization.
- Executives may access multiple factories.
- Users shall only view authorized machine information.

---

## Reliability

- Temporary telemetry interruptions shall not cause dashboard failure.
- Cached summary data may be used during short communication outages.
