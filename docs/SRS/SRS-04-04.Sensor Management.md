# 1. Overview

## 1.1 Purpose

This document defines the functional requirements for the **Sensor Management** module.

The Sensor Management module is responsible for managing the complete lifecycle of IoT sensors installed on industrial machines. It supports sensor registration, assignment, relocation, configuration, operational status monitoring, calibration tracking, and historical traceability.

A sensor is the source of telemetry data collected by the Factory Management System.

---

# 2. Business Scope

The module supports:

- Sensor Registration
- Sensor Configuration
- Sensor Assignment
- Sensor Relocation
- Sensor Status Management
- Sensor Calibration Information
- Sensor Lifecycle Management
- Sensor Search
- Sensor History
- Sensor Import / Export
- Audit Logging

The module does **not** manage telemetry storage or telemetry processing, which are covered by the Telemetry module.

---

# 3. Business Rules

- One Sensor belongs to **one Machine** at any point in time.
- A Machine may have **multiple Sensors**.
- A Sensor may be reassigned to another Machine.
- Historical assignments shall always be preserved.
- Historical telemetry remains associated with the Machine where the sensor was installed when the data was generated.
- Sensors shall never be physically deleted.

---

# 4. Sensor Information

Each sensor shall contain at least the following information.

| Field | Required |
|--------|----------|
| Sensor Code | Yes |
| Sensor Name | Yes |
| Sensor Type | Yes |
| Manufacturer | Yes |
| Model | No |
| Serial Number | Yes |
| Unit of Measure | Yes |
| Communication Protocol | Yes |
| Factory | Derived |
| Current Machine | No |
| Installation Date | Yes |
| Last Calibration Date | No |
| Next Calibration Date | No |
| Status | Yes |
| Description | No |

# 5. Functional Requirements

---

# FR-SEN-001 Create Sensor

## Description

The system shall allow authorized users to register a new sensor.

### Actors

- System Administrator
- Factory Manager

### Required Information

- Sensor Code
- Sensor Name
- Sensor Type
- Serial Number
- Communication Protocol
- Unit of Measure

### Business Rules

- Sensor Code must be unique.
- Serial Number must be unique.

### Acceptance Criteria

The sensor is successfully created.

---

# FR-SEN-002 Update Sensor

Authorized users shall update sensor information.

Editable fields include:

- Name
- Model
- Manufacturer
- Calibration Information
- Description

Sensor Code cannot be modified.

Audit logs shall be generated.

---

# FR-SEN-003 Disable Sensor

Sensors shall not be physically deleted.

Supported statuses:

- Active
- Inactive
- Retired

Historical data shall remain available.

---

# FR-SEN-004 View Sensor

The system shall display:

- General Information
- Current Machine
- Current Status
- Calibration Information
- Assignment History
- Latest Telemetry Timestamp

---

# FR-SEN-005 Search Sensor

Support searching by:

- Sensor Code
- Sensor Name
- Sensor Type
- Machine
- Factory
- Protocol
- Status

Support sorting and pagination.

---

# FR-SEN-006 Assign Sensor

A sensor may be assigned to a machine.

Assignment information:

- Machine
- Assignment Date
- Assigned By

Only one active assignment is allowed.

---

# FR-SEN-007 Relocate Sensor

The system shall allow relocating a sensor from one machine to another.

The system shall record:

- Previous Machine
- New Machine
- Effective Date
- Operator

Historical assignments shall remain unchanged.

---

# FR-SEN-008 View Assignment History

The system shall display:

- Previous Machine
- New Machine
- Assignment Date
- Removal Date
- Changed By

---

# FR-SEN-009 Sensor Status Management

Supported statuses:

- Online
- Offline
- Maintenance
- Calibration
- Fault

Status may be updated automatically or manually.

---

# FR-SEN-010 Calibration Management

The system shall maintain:

- Last Calibration Date
- Next Calibration Date
- Calibration Result
- Calibration Certificate Reference

Calibration history shall be preserved.

---

# FR-SEN-011 Calibration Reminder

The system shall notify responsible users before calibration is due.

Reminder period shall be configurable.

---

# FR-SEN-012 Sensor Dashboard

The sensor detail page shall display:

- Current Status
- Current Machine
- Latest Reading Timestamp
- Calibration Status
- Communication Status

---

# FR-SEN-013 Sensor History

Historical records shall include:

- Assignment History
- Calibration History
- Configuration History
- Status History

Historical records shall be immutable.

---

# FR-SEN-014 Communication Configuration

Authorized users may configure:

- Protocol
- Sampling Interval
- Communication Parameters

Configuration changes shall be audited.

---

# FR-SEN-015 Import Sensor

The system shall support importing sensors via Excel.

Validation includes:

- Duplicate Sensor Code
- Duplicate Serial Number
- Invalid Machine
- Invalid Protocol

---

# FR-SEN-016 Export Sensor

Authorized users shall export sensor information to:

- Excel
- CSV

---

# FR-SEN-017 Sensor Retirement

Retired sensors:

- Cannot be assigned to machines
- Cannot receive telemetry
- Remain available in historical reports

---

# FR-SEN-018 Audit Logging

The system shall record:

- Sensor Created
- Sensor Updated
- Sensor Assigned
- Sensor Relocated
- Calibration Updated
- Configuration Changed
- Sensor Disabled
- Sensor Retired

Each audit record shall contain:

- User
- Timestamp
- Action
- Previous Value
- New Value

# 7. Non-functional Considerations

- Sensor search should complete within **2 seconds** under normal operating conditions.
- Sensor assignment shall be transactional.
- Historical assignments shall never be modified.
- Calibration history shall remain immutable.
- Bulk import shall support at least **10,000 sensors** per file.
- Export operations shall respect factory-level authorization.
- Configuration changes shall be fully audited.
