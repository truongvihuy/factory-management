# 1. Overview

## 1.1 Purpose

This document defines the functional requirements for the **Factory Management** module.

The Factory Management module is responsible for managing the physical organizational structure of manufacturing facilities, including factories, workshops, and production lines.

It provides the hierarchical foundation used throughout the Factory Management System for machine assignment, authorization, telemetry, maintenance, incidents, dashboards, and reporting.

---

# 2. Business Scope

The module supports:

- Factory Management
- Workshop Management
- Production Line Management
- Factory Hierarchy
- Factory Status
- Factory Search
- Factory Archive
- Audit Logging

---

# 3. Factory Hierarchy

The system shall support the following hierarchy.

```text
Company
    └── Factory
            └── Workshop
                    └── Production Line
```

Business Rules:

- One Company may contain multiple Factories.
- One Factory may contain multiple Workshops.
- One Workshop may contain multiple Production Lines.
- One Production Line belongs to one Workshop.
- One Workshop belongs to one Factory.

Historical hierarchy changes shall be traceable.

---

# 4. Functional Requirements

---

# FR-FAC-001 Create Factory

Authorized users shall create a Factory.

Required fields:

- Factory Code
- Factory Name
- Company
- Address
- Time Zone
- Status

Factory Code shall be unique within the Company.

---

# FR-FAC-002 Update Factory

Authorized users shall update:

- Name
- Address
- Contact Information
- Description
- Status

Factory Code cannot be modified.

Audit logs shall be generated.

---

# FR-FAC-003 Disable Factory

Factories shall not be physically deleted.

Supported statuses:

- Active
- Inactive

Inactive factories shall not accept new operational data.

Historical records shall remain available.

---

# FR-FAC-004 View Factory

Display:

- Factory Information
- Number of Workshops
- Number of Production Lines
- Number of Machines
- Number of Active Alerts
- Number of Open Incidents

---

# FR-FAC-005 Search Factory

Support searching by:

- Factory Code
- Factory Name
- Company
- Status

Support pagination and sorting.

---

# FR-FAC-006 Create Workshop

Authorized users shall create Workshops.

Required fields:

- Workshop Code
- Workshop Name
- Factory

Workshop Code shall be unique within the Factory.

---

# FR-FAC-007 Update Workshop

Authorized users may update:

- Workshop Name
- Description
- Status

Audit logs shall be generated.

---

# FR-FAC-008 Disable Workshop

Workshops shall not be physically deleted.

Historical information shall remain available.

---

# FR-FAC-009 Create Production Line

Authorized users shall create Production Lines.

Required fields:

- Line Code
- Line Name
- Workshop

Production Line Code shall be unique within the Workshop.

---

# FR-FAC-010 Update Production Line

Authorized users may update:

- Line Name
- Description
- Status

Audit logs shall be generated.

---

# FR-FAC-011 Disable Production Line

Production Lines shall not be physically deleted.

Historical information shall remain available.

---

# FR-FAC-012 View Factory Hierarchy

Users shall view the complete hierarchy:

Company

↓

Factory

↓

Workshop

↓

Production Line

The hierarchy shall support expand/collapse navigation.

---

# FR-FAC-013 Production Line Assignment Summary

The system shall display:

- Number of Machines
- Active Machines
- Active Alerts
- Open Incidents

for each Production Line.

---

# FR-FAC-014 Factory Dashboard Summary

The system shall display:

- Total Workshops
- Total Production Lines
- Total Machines
- Running Machines
- Offline Machines
- Maintenance Machines

---

# FR-FAC-015 Export Factory Structure

Authorized users shall export the factory hierarchy.

Supported formats:

- Excel
- CSV

---

# FR-FAC-016 Archive Factory

Archived factories:

- Remain searchable
- Preserve historical data
- Cannot receive new operational records

---

# FR-FAC-017 Audit Logging

The system shall record:

- Factory Created
- Factory Updated
- Workshop Created
- Workshop Updated
- Production Line Created
- Production Line Updated
- Factory Disabled
- Workshop Disabled
- Production Line Disabled

Each audit record shall include:

- User
- Timestamp
- Action
- Previous Value
- New Value

# 6. Non-functional Considerations

## Performance

- Factory search should complete within **2 seconds**.
- Hierarchy loading should complete within **2 seconds**.

---

## Availability

- Factory management services should achieve **99.9% availability**.

---

## Security

- Users shall only access authorized factories.
- Factory modifications require appropriate permissions.
- All changes shall be audited.

---

## Data Integrity

- Factory hierarchy shall remain consistent.
- Historical hierarchy changes shall never be deleted.
- Production Lines shall always belong to one Workshop.
- Workshops shall always belong to one Factory.
