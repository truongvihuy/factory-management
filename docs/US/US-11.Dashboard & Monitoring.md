# FT-DASH-01 Real-time Dashboard

## US-DASH-001 View Factory Dashboard

### Description

**As a** Factory Manager

**I want** to view the factory dashboard

**So that** I can monitor overall factory operations in real time.

### Business Value

- Improve operational visibility.
- Reduce response time.
- Support management decisions.

### Priority

Critical

### Story Points

8

### Acceptance Criteria

Dashboard displays:

- Total Factories
- Total Workshops
- Total Production Lines
- Total Machines
- Online Machines
- Offline Machines
- Running Machines
- Active Alerts
- Active Incidents

Dashboard refreshes automatically.

---

## US-DASH-002 Switch Factory

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-080 | Dashboard displays only factories the user is authorized to access. |
| BR-081 | Dashboard data refreshes automatically in near real time. |
| BR-082 | KPI calculations use aggregated telemetry data. |
| BR-083 | Machine status is synchronized with the latest telemetry. |
| BR-084 | Dashboard layouts are stored per user. |
| BR-085 | Users may customize their own dashboards only. |
| BR-086 | Dashboard exports reflect the currently applied filters. |

# 7. Non-functional Considerations

## Performance

- Dashboard initial load ≤ **3 seconds**
- Widget refresh ≤ **2 seconds**
- KPI calculation uses pre-aggregated data

---

## Availability

Dashboard availability ≥ **99.9%**

---

## Scalability

Support:

- 5,000 machines
- 10 factories
- Thousands of concurrent dashboard users

---

## Security

- Factory-level Role-Based Access Control (RBAC)
- Data isolation between companies

---

## Usability

- Responsive UI
- Large-screen support
- Auto refresh
- Dark mode ready
