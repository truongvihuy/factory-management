# 1. Overview

## 1.1 Purpose

This document defines the functional requirements for the **Machine Management** module.

The module is responsible for managing the complete lifecycle of industrial machines, including registration, configuration, assignment, relocation, operational status, maintenance information, and historical records.

Machine Management serves as the foundation for Telemetry, Alerts, Maintenance, Incidents, Reporting, and Dashboard modules.

---

# 2. Business Scope

The module supports:

- Machine Registration
- Machine Information Management
- Machine Assignment
- Machine Relocation
- Machine Status Management
- Machine Configuration
- Running Hour Management
- Maintenance Information
- Warranty Information
- Machine Search
- Machine History
- Machine Lifecycle
- Audit Logging

Production management is outside the scope of this module.

---

# 3. Machine Lifecycle

```text
Registered
      │
Installed
      │
Running
      │
Maintenance
      │
Running
      │
Retired
```

Machines shall never be physically deleted.

# 5. Functional Requirements

---

# FR-MCH-001 Create Machine

## Description

The system shall allow authorized users to register a new machine.

### Actors

- Factory Manager
- System Administrator

### Required Information

- Machine Code
- Machine Name
- Machine Type
- Manufacturer
- Factory
- Production Line

### Business Rules

- Machine Code must be unique.
- One Machine belongs to one Production Line.
- Factory is derived from the selected Production Line.

### Acceptance Criteria

The machine is successfully created and appears in the machine list.

---

# FR-MCH-002 Update Machine

Authorized users shall update machine information.

Editable fields include:

- Machine Name
- Model
- Manufacturer
- Warranty Expiry
- Description

Machine Code cannot be modified.

Audit logs shall be recorded.

---

# FR-MCH-003 Disable Machine

Machines shall not be physically deleted.

Supported statuses:

- Active
- Inactive
- Retired

Historical operational data shall remain unchanged.

---

# FR-MCH-004 View Machine

The system shall display:

- General Information
- Current Status
- Current Production Line
- Running Hours
- Maintenance Summary
- Incident Summary
- Alert Summary
- Sensor List

---

# FR-MCH-005 Search Machine

Support searching by:

- Machine Code
- Machine Name
- Machine Type
- Factory
- Workshop
- Production Line
- Manufacturer
- Status

Support sorting and pagination.

---

# FR-MCH-006 Assign Production Line

A machine shall be assigned to one Production Line.

Assignment information:

- Production Line
- Effective Date
- Assigned By

Assignment history shall be retained.

---

# FR-MCH-007 Relocate Machine

A machine may be relocated to another Production Line.

The system shall:

- Record relocation date
- Record previous Production Line
- Record new Production Line
- Record operator
- Preserve historical assignments

Historical telemetry shall remain associated with the original Production Line at the time the data was collected.

---

# FR-MCH-008 View Assignment History

The system shall display all historical Production Line assignments.

Displayed information:

- Previous Production Line
- New Production Line
- Effective Date
- Changed By

---

# FR-MCH-009 Machine Status Management

Supported statuses:

- Running
- Idle
- Stopped
- Maintenance
- Offline
- Error

Status may be updated automatically by telemetry or manually by authorized users.

---

# FR-MCH-010 Running Hour Management

The system shall maintain machine running hours.

Running hours may be:

- Updated automatically from telemetry
- Adjusted manually by authorized users (with audit log)

Running hours are used for maintenance scheduling.

---

# FR-MCH-011 Warranty Management

The system shall maintain warranty information.

The system shall notify users before warranty expiration (configurable).

---

# FR-MCH-012 Maintenance Information

The machine detail shall display:

- Last Maintenance
- Next Maintenance
- Open Work Orders
- Maintenance History

---

# FR-MCH-013 Incident Information

The machine detail shall display:

- Open Incidents
- Incident History
- SLA Status

---

# FR-MCH-014 Alert Information

The machine detail shall display:

- Active Alerts
- Alert History
- Alert Severity
- Alert Acknowledgement Status

---

# FR-MCH-015 Sensor Association

The system shall display all sensors currently assigned to the machine.

Historical sensor assignments shall be accessible.

---

# FR-MCH-016 Machine Dashboard Summary

Machine summary shall include:

- Current Status
- Active Alerts
- Running Hours
- Energy Consumption
- Latest Telemetry Timestamp

---

# FR-MCH-017 Machine History

The system shall preserve:

- Assignment History
- Maintenance History
- Incident History
- Alert History
- Sensor Assignment History
- Configuration Change History

Historical records shall be immutable.

---

# FR-MCH-018 Machine Configuration

Authorized users may configure machine parameters including:

- Alert Threshold Profile
- Maintenance Schedule
- Operating Limits
- Monitoring Configuration

Configuration changes shall be audited.

---

# FR-MCH-019 Import Machine

The system shall support bulk machine import via Excel.

Validation shall include:

- Duplicate Machine Code
- Invalid Factory
- Invalid Production Line
- Missing Required Fields

Import results shall indicate:

- Success Records
- Failed Records
- Error Details

---

# FR-MCH-020 Export Machine

Authorized users shall export machine information to:

- Excel
- CSV

Export shall respect authorization rules.

---

# FR-MCH-021 Machine Retirement

Machines may be retired.

Retired machines:

- Cannot receive new telemetry
- Cannot receive new maintenance schedules
- Remain available in historical reports

---

# FR-MCH-022 Audit Logging

The system shall record:

- Machine Created
- Machine Updated
- Machine Disabled
- Machine Retired
- Production Line Changed
- Running Hour Adjusted
- Configuration Changed

Each audit record shall contain:

- User
- Timestamp
- Action
- Previous Value
- New Value

# 7. Non-functional Considerations

- Machine search should return results within **2 seconds** under normal operating conditions.
- Machine detail pages should load within **2 seconds**.
- Assignment changes shall be processed transactionally.
- Historical records shall never be overwritten.
- All configuration changes shall be audited.
- Bulk import shall support at least **5,000 machines** per import file.
- Export operations shall respect factory-level authorization.
- Concurrent updates to the same machine shall preserve data consistency.
