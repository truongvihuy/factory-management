# 2. Epic Goal

Provide the ability to manage factory organizational structures within an organization.

The module shall support:

- Factory Management
- Workshop Management
- Production Line Management

while maintaining historical changes and ensuring data integrity.

# FT-FAC-01 Factory Management

---

## US-FAC-001 Create Factory

### Description

**As a** System Administrator

**I want** to create a factory

**So that** machines and production resources can be managed under the correct location.

### Business Value

Support multi-factory architecture.

### Priority

Critical

### Story Points

5

### Acceptance Criteria

#### AC-01 Create Successfully

**Given**

- User has permission.
- Organization exists.

**When**

Administrator creates a factory.

**Then**

- Factory is created.
- Status = Active.
- Audit Log recorded.

---

#### AC-02 Duplicate Factory Code

Factory Code must be unique within the organization.

---

#### AC-03 Invalid Organization

Cannot create a factory without selecting an existing organization.

---

#### AC-04 Unauthorized

Only authorized users may create factories.

---

## US-FAC-002 Update Factory

### Description

As a System Administrator,

I want to update factory information,

So that factory information remains accurate.

### Acceptance Criteria

- Update factory information.
- Factory Code cannot be modified.
- Audit Log generated.

Story Point: 3

---

Story Point: 2

---

## US-FAC-004 Search Factory

Support searching by:

- Code
- Name

- Status

Support:

- Sorting
- Pagination

Story Point: 3

---

## US-FAC-005 Archive Factory

Archive inactive factories.

### Acceptance Criteria

Factory cannot be archived when:

- Active workshops exist.
- Active production lines exist.
- Active machines exist.
- Active users are assigned.

Audit Log generated.

Story Point: 5

---

## US-FAC-006 Restore Factory

Restore archived factories.

Historical information shall remain unchanged.

Story Point: 3

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-010 | Factory Code must be unique within an Organization. |
| BR-011 | Workshop Code must be unique within a Factory. |
| BR-012 | Production Line Code must be unique within a Workshop. |
| BR-013 | A Factory belongs to one Organization. |
| BR-014 | A Workshop belongs to one Factory. |
| BR-015 | A Production Line belongs to one Workshop. |
| BR-016 | Historical hierarchy changes shall be retained. |
| BR-017 | Archived entities become read-only. |
| BR-018 | Factory Code cannot be modified after creation. |
| BR-019 | All changes shall generate Audit Logs. |

# 6. Dependencies

- Authentication & Authorization
- Organization Management
- Audit Log
- Machine Management

---

# 7. Non-functional Considerations

## Security

- Factory data shall be accessible only by authorized users.
- Permissions shall be applied at Factory level.

---

## Performance

- Factory hierarchy shall load within 2 seconds for normal operations.
- Search results shall return within 2 seconds.

---

## Scalability

Support:

- Thousands of factories.
- Tens of thousands of workshops.
- Hundreds of thousands of production lines.

---

## Auditability

Every Create, Update, Archive, Restore operation shall generate Audit Logs.
