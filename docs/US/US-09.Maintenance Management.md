# FT-MNT-01 Maintenance Plan

## US-MNT-001 Create Maintenance Plan

### Description

**As a** Maintenance Planner

**I want** to create a maintenance plan

**So that** machines are serviced periodically.

### Business Value

- Reduce downtime
- Extend equipment lifetime
- Improve reliability

### Priority

Critical

### Story Points

8

### Acceptance Criteria

- Support maintenance types:
  - Preventive
  - Corrective
  - Predictive
- Select target machine.
- Configure maintenance interval.
- Save maintenance plan.

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-060 | Three maintenance types shall be supported: Preventive, Corrective, Predictive. |
| BR-061 | Every maintenance activity requires an approved schedule before execution. |
| BR-062 | Every maintenance task shall use a checklist. |
| BR-063 | Checklist results become read-only after verification. |
| BR-064 | Spare part replacement shall be recorded permanently. |
| BR-065 | Maintenance history shall never be deleted. |
| BR-066 | Sensor replacement shall be recorded as part of machine maintenance. |
| BR-067 | Every maintenance operation shall generate an Audit Log. |

# 7. Non-functional Considerations

## Performance

- Schedule generation ≤ 5 seconds.
- Maintenance history query ≤ 2 seconds.

---

## Availability

Maintenance module availability ≥ **99.9%**.

---

## Scalability

Support:

- Thousands of maintenance plans.
- Millions of maintenance records.
- Multiple factories.

---

## Security

- Only authorized maintenance personnel can create or execute maintenance tasks.
- Approval requires Supervisor permission.

---

## Auditability

Audit Logs shall be generated for:

- Plan Creation
- Schedule Update
- Approval
- Execution
- Checklist Completion
- Spare Part Replacement
- Maintenance Completion
