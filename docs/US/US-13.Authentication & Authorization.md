# 2. Epic Goal

Provide secure authentication and factory-level authorization for all users accessing the Factory Management System.

The system shall support local account authentication, role-based access control (RBAC), factory-level permissions, password management, and session management.

# 4. User Stories

# FT-AUTH-01 Local Authentication

## US-AUTH-001 Login

**As a** User

**I want** to log in using my username and password

**So that** I can securely access the system.

### Acceptance Criteria

- Username and password are required.
- Credentials are validated.
- Only active accounts may log in.
- Failed logins display an appropriate error.
- Successful login creates a user session.

Story Point: **5**

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-130 | Authentication uses local accounts only. |
| BR-131 | Passwords are stored as secure hashes. |
| BR-132 | A user may belong to multiple factories. |
| BR-133 | Authorization is enforced at the factory level. |
| BR-134 | Only active accounts can authenticate. |
| BR-135 | Authentication events shall be recorded in the Audit Log. |
| BR-136 | Sessions expire automatically after inactivity. |

# 7. Non-functional Considerations

## Performance

- Login ≤ **2 seconds**
- Authorization check ≤ **100 ms**

---

## Availability

Authentication service availability ≥ **99.9%**

---

## Security

- Password hashing (Argon2 or bcrypt)
- HTTPS only
- Session expiration
- CSRF/XSS protection
- Brute-force protection

---

## Scalability

Support:

- Multi-company
- Multi-factory
- Thousands of concurrent users

---

# 8. Definition of Done

A User Story is complete when:

- Acceptance Criteria pass.
- Authentication is secure.
- Authorization rules are enforced.
- Audit Logs are generated.
- Unit Tests pass.
- Integration Tests pass.
- Product Owner approves.
