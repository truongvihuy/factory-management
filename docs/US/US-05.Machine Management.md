# 2. Epic Goal

Provide complete lifecycle management for industrial machines.

The system shall support machine registration, assignment, relocation, status management, lifecycle tracking, history management, and asset archival while preserving complete historical records.

# FT-MAC-01 Register Machine

## US-MAC-001 Register Machine

### Description

**As a** Factory Manager

**I want** to register a new machine

**So that** it can be monitored and managed throughout its lifecycle.

### Business Value

- Centralize machine information.
- Enable telemetry collection.
- Enable maintenance planning.

### Priority

Critical

### Story Points

5

### Acceptance Criteria

#### AC-01 Successful Registration

**Given**

- User has permission.
- Factory exists.
- Workshop exists.
- Production Line exists.

**When**

A new machine is created.

**Then**

- Machine is created.
- Status = Active.
- Running Hour = 0.
- Audit Log generated.

---

#### AC-02 Duplicate Machine Code

Machine Code must be unique within an Organization.

---

#### AC-03 Duplicate Serial Number

Serial Number cannot already exist.

---

#### AC-04 Required Fields

The following fields are mandatory:

- Machine Code
- Machine Name
- Machine Type
- Factory
- Workshop
- Production Line
- Manufacturer
- Installation Date

# FT-MAC-09 Archive / Restore

## US-MAC-011 Archive Machine

Archive machine.

### Acceptance Criteria

Machine cannot be archived if:

- Open maintenance exists.
- Open incident exists.
- Active telemetry collection exists.

Machine history must remain available.

# 5. Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-020 | Machine Code shall be unique within an Organization. |
| BR-021 | Serial Number shall be unique. |
| BR-022 | A machine belongs to one Production Line at a time. |
| BR-023 | Production Line changes shall retain historical records. |
| BR-024 | Workshop changes shall retain historical records. |
| BR-025 | Machine Code cannot be modified after creation. |
| BR-026 | Machine status changes shall be recorded. |
| BR-027 | Archived machines become read-only. |
| BR-028 | Machine history shall never be deleted. |
| BR-029 | Audit Logs shall be generated for all changes. |

# 7. Non-functional Considerations

## Security

- Users can only manage machines within authorized factories.
- Factory-level RBAC shall be enforced.

---

## Performance

- Search response ≤ 2 seconds.
- View machine details ≤ 2 seconds.

---

## Availability

- Machine Management availability ≥ 99.9%.

---

## Scalability

Support:

- 5,000+ machines.
- Millions of historical records.
- High-frequency telemetry references.

---

## Auditability

The following operations shall generate Audit Logs:

- Register
- Update
- Status Change
- Production Line Assignment
- Relocation
- Archive
- Restore
